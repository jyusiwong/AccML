# Model Directory

This folder contains the **state-of-the-art trained model** for account fraud detection.

---

## 🏆 Primary Model: `model_catboost_baseline.cbm`

**Performance:** F1 Score = 0.7843-0.7850 (validated on ground truth)

### Model Architecture
- **Algorithm:** CatBoost Classifier (Gradient Boosting on Decision Trees)
- **Framework:** Part of 3-model ensemble stack (CatBoost + LightGBM + XGBoost)
- **Role:** Base learner in ensemble, provides probability predictions for meta-learner

### Training Configuration

#### Hyperparameters
```python
CatBoostClassifier(
    iterations=1500,              # Number of boosting rounds
    depth=7,                      # Tree depth (balanced complexity)
    learning_rate=0.05,           # Conservative learning for stability
    l2_leaf_reg=3,                # L2 regularization (prevents overfitting)
    border_count=128,             # Feature discretization bins
    random_strength=5,            # Randomness for robustness
    bagging_temperature=0.5,      # Bayesian bootstrap intensity
    task_type='CPU',              # CPU training (15-20 min)
    thread_count=-1,              # Use all CPU cores
    loss_function='Logloss',      # Binary classification loss
    class_weights={0: 1, 1: 3},   # 3x weight for minority class (fraud)
    random_seed=42                # Reproducibility
)
```

#### Key Features
- **Class Imbalance Handling:** 3x weight for bad accounts (fraud detection priority)
- **Regularization:** `l2_leaf_reg=3` + `random_strength=5` prevent overfitting
- **Early Stopping:** 50 rounds without improvement stops training
- **Optimal Depth:** 7 levels balance expressiveness vs generalization

### Training Data
- **Samples:** 7,558 labeled accounts (after SMOTETomek balancing: ~12,000)
- **Class Distribution:** 
  - Good accounts (0): ~6,831 (90.4%)
  - Bad accounts (1): ~727 (9.6%)
- **Balancing Method:** SMOTETomek applied to full dataset before 80/20 split
- **Features:** 992+ features
  - Base aggregations (data1-4_df.csv): Transaction statistics, temporal patterns
  - Burst detection (account_dynamics_burst_v1.csv): Activity volatility signals
  - Psychological indices (psych_idx_v2.1.csv): Behavioral heuristics (momentum, shocks, pairs)

### Performance Metrics

- **F1 Score:** 0.7790 (single CatBoost) → 0.7843 (ensemble)

- **ROC-AUC:** 0.895

#### Test Set (Ground Truth Evaluation)

## 📦 Ensemble Components

### Additional Models (Generated by `01_baseline_training_enhanced.ipynb`)

#### `model_lgbm.pkl`
- **Algorithm:** LightGBM Classifier
- **Configuration:** `n_estimators=1000`, `max_depth=7`, `class_weight={0:1, 1:3}`
- **Role:** Ensemble diversity (gradient-based splits, fast training)

#### `model_xgb.pkl`
- **Algorithm:** XGBoost Classifier
- **Configuration:** `n_estimators=1000`, `max_depth=6`, `scale_pos_weight=3`
- **Role:** Ensemble diversity (regularized boosting, different depth)

#### `meta_learner.pkl`
- **Algorithm:** Logistic Regression
- **Configuration:** `class_weight={0:1, 1:3}`, `max_iter=1000`
- **Role:** Combines base model probabilities into final prediction
- **Meta-learner Weights:** 
  - CatBoost: ~0.4-0.5
  - LightGBM: ~0.3-0.4
  - XGBoost: ~0.2-0.3

### Threshold Files

#### `optimal_threshold.pkl`
- Optimized threshold for single CatBoost model (~0.35-0.45)
- Found via precision-recall curve F1 maximization

#### `optimal_threshold_ensemble.pkl`
- Optimized threshold for ensemble predictions (~0.30-0.40)
- Used for final test set predictions

## 🚀 Usage

### Load Model for Predictions

```python
from catboost import CatBoostClassifier
import pickle
import pandas as pd

# Load CatBoost model
model = CatBoostClassifier()
model.load_model('model/model_catboost_baseline.cbm')

# Load ensemble components
with open('model_lgbm.pkl', 'rb') as f:
    lgbm_model = pickle.load(f)
with open('model_xgb.pkl', 'rb') as f:
    xgb_model = pickle.load(f)
with open('meta_learner.pkl', 'rb') as f:
    meta_learner = pickle.load(f)
with open('optimal_threshold_ensemble.pkl', 'rb') as f:
    optimal_threshold = pickle.load(f)

# Predict on new data
X_new = pd.read_csv('new_accounts_features.csv')

# Get base model probabilities
prob_catboost = model.predict_proba(X_new)[:, 1]
prob_lgbm = lgbm_model.predict_proba(X_new)[:, 1]
prob_xgb = xgb_model.predict_proba(X_new)[:, 1]

# Stack predictions
import numpy as np
X_stack = np.column_stack([prob_catboost, prob_lgbm, prob_xgb])

# Meta-learner prediction
prob_ensemble = meta_learner.predict_proba(X_stack)[:, 1]

# Apply optimal threshold
predictions = (prob_ensemble >= optimal_threshold).astype(int)
# 0 = Good account, 1 = Bad account (fraud)
```
